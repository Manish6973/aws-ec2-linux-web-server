# CyberAlpha - AWS EC2 Web Server

# Project Overview
Hosted a professional website using AWS EC2.

# AWS Services
  Amazon EC2
  Security Groups
  Default VPC

# Technologies
  Amazon Linux 2023
  Apache HTTP Server
  HTML
  CSS
  Linux

# Implementation
1. Launched EC2 instance.
2. Configured SSH and HTTP in Inbound rule .
3. Installed Apache.
4. Created website using HTML and CSS.
5. Configured Linux permissions.
6. Tested website using Public IPv4.

# Security
  SSH restricted to My IP.
  HTTP allowed for public access.
  Website files use 644 permissions.
  Directories use 755 permissions.
